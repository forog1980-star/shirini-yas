# اعتبار و منبع تصاویر نمونه محصولات یاس

این تصاویر صرفاً برای نمایش نمونه‌ای ویترین استفاده می‌شوند و عکس واقعی محصولات تولیدی شیرینی‌پزی یاس نیستند. تصاویر از صفحه‌های دارای مجوز رایگان Pexels انتخاب شده‌اند و در زمان اجرای `npm run build` یا `npm run dev` در `public/assets/products/` دانلود می‌شوند تا مرورگر بازدیدکننده به میزبان تصویر خارجی وابسته نباشد.
